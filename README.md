# PROJET 52 CARTES

Catalogue interactiv de jeux de société adaptés à du matériel courant : jeux de cartes, jeux de dés, jeux papier-crayon et autres jeux nécessitant peu de matériel spécialisé.

🎲 Plus de 90 jeux référencés.

Consulter le catalogue
👉 https://user.github.io/projet52cartes/


# LE SITE WEB

Le site permet de filtrer les jeux par :
- Nombre de joueurs
- Age
- Matériel requis
- Nom de l'adaptation
- Nom du jeu original
- Auteur
- Année de publication 
- Catégorie BGG (party, family, abstrait, stratégie)
- Autres étiquettes (coopératif, plis, enchères, bluff, déduction, reflexes, stop ou encore, rôles cachés, roll & write...)
- 3 filtres rapides: FAV = mes favoris, NEW = derniers ajouts au catalogue, FLASH = jeux faciles à comprendre pour un démarrage rapide

Les résultats sont triés selon les critères suivants:
- D'abord les jeux idéaux pour toutes les configurations de joueurs sélectionnées
- Ensuite les jeux idéaux pour au moins une des configurations sélectionnées
- Enfin les jeux qui peuvent être joués avec toutes les configurations sélectionnées
- A l'intérieur de ces bloques, les résultats sont triés selon le ranking BGG, avec deux  modificateurs:
     - Les jeux ajoutés au catalogue dans les 3 derniers mois bénéficient d'une promotion invesement proportionnelle au temps depuis leur ajout
     - Les jeux peuvent être avancés ou reculés selon mon avis personnel du jeu en soi et de l'adaptation que j'ai ai faite
 
Chaque résultat présente les éléments suivants:
- Nom de l'adaptation
- Ranking BGG
- Nom du jeu d'origine
- Nombre de joueurs (conseillé et idéal)
- Age minimale conseillée
- Matériel nécessaire
- Catégories BGG
- Description sommaire du jeu
- Auteur(s), année de publication
- Evaluation de la fidélité de l'adaptation par rapport au jeu original
- Lien vers la règle en format mobile (Google Docs)
- Lien vers la règle et matériel additionnel (aides de jeu, feuilles de score...) en PDF
- Lien vers la fiche BGG du jeu original


# UN MOT SUR LES ADAPTATIONS

Les jeux présentés dans ce catalogue sont des adaptations non officielles permettant de reproduire l'expérience ludique avec du matériel facilement disponible.
Ce projet a pour objectif de faire découvrir des jeux et leurs mécanismes.
Si une adaptation vous plaît, pensez à soutenir les auteurs, autrices et éditeurs en achetant les jeux originaux lorsque ceux-ci sont disponibles.
